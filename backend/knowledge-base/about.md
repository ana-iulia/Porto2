# About Ana-Iulia Enache

# Bio

Hi, I'm a Software Engineer. I build scalable backend systems, AI-powered developer tools, and cloud-native platforms that help teams understand, monitor, and operate complex distributed systems.

I have over five years of professional experience building backend
applications, distributed systems and cloud-native services. My primary
background is in Java, with professional experience in Go and Python.
Recently, I've been transitioning toward AI engineering, developing
tools that leverage Retrieval-Augmented Generation (RAG), LangChain, and
LLMs to automate log analysis, troubleshooting and developer workflows.

# Background

My career began as a Java developer, where I worked extensively with
Spring Boot, microservices, REST APIs, Kafka, AWS, Docker, PostgreSQL,
Hibernate, and JPA. Later, I expanded into Go development, building
applications that use gRPC, UDP, SQLC, PostgreSQL, SQLite, and
observability tools such as Grafana, Prometheus, Loki, and Promtail.

Alongside my engineering experience, I worked as a programming trainer,
teaching Python, JavaScript, and programming fundamentals to students
aged 11--18. Teaching strengthened my communication skills and
reinforced my passion for continuous learning.

Today, my work spans backend engineering, platform engineering, DevOps, and AI. I develop cloud-native applications, manage Kubernetes deployments, automate infrastructure, and build AI-powered tools for large-scale log analysis and troubleshooting. My recent projects involve Retrieval-Augmented Generation (RAG), LangChain, LLMs, Grafana integrations, and intelligent systems that analyze large volumes of operational data to help engineers quickly identify and resolve production issues.
