# Projects

## Lumi
A mobile-first health companion for underrepresented women (South Asian and Black women).
- Stack: FastAPI, LangChain, ChromaDB, OpenAI, Supabase, React 19, Tailwind CSS
- Built a full RAG pipeline grounded in NHS-aligned health knowledge
- Symptom tracking with gamification (streaks, points, badges)
- GP appointment preparation with narrative summary and suggested questions
- Email-confirmed auth via Supabase
- Role: sole developer, full-stack

## Deal Agent Framework
Multi-agent system for automated deal price analysis.
- Stack: Python, LangChain, OpenAI
- Agents use tool-calling with a planning loop and ephemeral memory
- Fine-tuned model for price estimation
- Role: sole developer

## LLM Fine-tuning Pipeline
End-to-end fine-tuning for price prediction tasks.
- Stack: Python, Hugging Face, LoRA, JSONL
- JSONL dataset preparation, LoRA training, before/after evaluation
- Deployed inference API

## RAG Evaluation Framework
Systematic evaluation of RAG pipeline quality.
- Measures retrieval precision, answer faithfulness, latency
- Tests different chunking sizes and embedding strategies
